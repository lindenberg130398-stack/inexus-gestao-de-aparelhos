# iNexus - Gestão de Aparelhos

Sistema web para gestão de estoque, compras, custos, vendas, clientes, fornecedores, financeiro, lucros e relatórios.

## Publicação

O projeto completo usa frontend, API e banco de dados. Para publicar tudo de forma integrada, use o deploy do Replit ou hospede a API e o banco separadamente. O Netlify pode hospedar apenas a parte estática, caso a API seja configurada em outro serviço.

O repositório não inclui segredos, dependências instaladas ou arquivos temporários.
