# iNexus - Gestão de Aparelhos

Sistema web para gestão de estoque, compras, custos, vendas, clientes, fornecedores, financeiro, lucros e relatórios.

## Aplicação publicada

https://nexus-gestao-de-aparelhos.replit.app

## Estrutura

- artifacts/nexus-aparelhos: interface web do iNexus
- artifacts/api-server: API e rotas do sistema
- lib: contratos OpenAPI e cliente compartilhado
- attached_assets: logo e assets do projeto

## Como usar o código

O projeto completo usa frontend, API e banco de dados. Para publicar tudo de forma integrada, use o deploy do Replit ou hospede a API e o banco separadamente.

Antes de executar o frontend fora do Replit, rode:

bash RECONSTRUIR-INDEX.sh

Esse comando recria o arquivo artifacts/nexus-aparelhos/index.html. O arquivo foi armazenado em partes hexadecimais para compatibilidade com a proteção de upload da conexão do GitHub.

O repositório não inclui segredos, dependências instaladas ou arquivos temporários.
